# 这个亲友团带着宝宝回“娘家”了

> 更新时间：2026-09-16 (UTC+8)

点击蓝字关注我们，了解更多活动资讯

母亲节前夕，我院生殖医学中心来了一个11人的特殊亲友团。原来，这一天是陈女士的双胞胎宝宝一周岁生日，她和此前助孕成功的钟女士相约来到我院生殖医学中心，把这份幸福与曾经和她们一起努力的白衣天使们共同分享，以表感激。

2016年初，曾在北京助孕失败的陈女士听闻我院诊治不孕不育服务好、水平高，她毅然从邻市踏上了来韶关的火车，走进了时任生殖医学中心主任陈艳的诊室。

看到身高不到1米65，体重却达到200斤的陈女士，陈艳极力建议她先减肥治疗。陈女士表示此前多次减肥失败且高龄，再三要求助孕。综合考虑后，陈艳开始为其助孕促排卵，但最后还是因卵泡发育不理想取消了周期。

两个月后，陈艳调整了促排方案，同时加大启动剂量再次为陈女士促排。这次非常顺利地拿到了三枚好胚胎，可惜的是在移植一枚优质囊胚后好孕未能如期而至。

（陈艳在为患者取卵）

几个月后，陈艳为陈女士移植了两枚冷冻胚胎。这次可谓喜忧参半，喜的是好孕终于降临，忧的是怀了三胞胎（其中一个是单卵双胎），陈女士不得不面临减胎的抉择。她最终未采纳医生的建议，在孕8周时减灭了一胎，留下了单卵双胎。****

陈女士享受着做孕妈妈的快乐，但孕15周时，意外还是发生了。陈女士出现了**双胎妊娠输血综合征**的症状。虽赴省城处理但结局仍不理想，陈女士不得不忍受巨大的悲痛实施了引产手术。

● ●●  生殖医学中心团队定期针对疑难病例进行探讨

2019年7月，陈女士又来了。

“我相信你，相信你们的助孕技术。这几年我已成功减重50斤。”陈女士眼神里透着渴求和坚毅的光芒。

“确实不容易。但也请相信有志者事竟成。”陈艳副院长赞叹陈女士这几年减肥成功的决心和毅力。

这一次，幸运之神一直眷顾。新鲜周期移植两枚优质胚胎后，陈女士再次双胎妊娠。2020年5月6日，她的一对龙凤胎宝宝顺利降生。

相较陈女士的艰辛，钟女士的幸福来得相对简单和容易。十年前在省城助孕活产一女婴后，而今又在我院一次助孕诞下麟儿，凑成了一个“好”字。

“今天是我家宝宝一周岁生日，再过三天就是母亲节了，是你们圆了我做母亲的梦。你们是我们家的幸运之神和幸福天使！**在这个特别的日子里，我们的三对亲戚朋友也一起过来了，希望她们能接住好孕。**”陈女士说着郎朗大笑起来。

陈艳在工作中

陈艳说，感谢你们的信任，感谢你们以这种方式回“娘家”，我们必将竭尽所能，助力这三个家庭和更多有需要的家庭圆梦！

**阳大夫小科普**

**双胎输血综合征：**

双胎输血综合征是双胎妊娠过程中一种非常严重且少见的并发症，是由于胎盘存在表层以及深层血管吻合所致。静脉或者动脉的吻合可能会造成压力高的动脉血流向压力低的静脉，出现双胎输血现象。由于双胎输血，可能会导致输出血的胎儿即供血儿循环血量减少，出现严重失血，而受血儿血容量增加，造成充血性器官衰竭等病症发生。

双胎输血综合征的病因目前尚不完全明确，可能是由于双羊膜囊、单绒毛膜所致。在单卵双胎中有60%—70%为单绒毛膜双羊膜囊，单绒毛膜双羊膜囊中有10%-15%为双胎输血综合征。
